# 数据治理知识图谱 · Data Atlas

一套以企业数据管理与治理为主线的中文知识工作台，连接隐私工程、业务风控、AI 数据处理与 TPM 项目交付。

学习版入口：[`learn.html`](./learn.html)。前 1–3 层为体系、模块和概念关键词；第 4–6 层逐步展开学习角度、具体问题，以及完整的白话讲解、例子和对比表。导图支持拖动、缩放、折叠和分支定位，讲解区适合连续阅读。

学习版覆盖全部 47 个主题，每个主题有解释、机制、教学案例、对比表、误区及自测。教学案例均为演示场景。内容位于 `learning-governance.json`、`learning-privacy.json`、`learning-delivery.json`，主题 ID 与 `knowledge.json` 对应。原有速查版仍从 `index.html` 进入。

模块、主题和正文专业词汇提供中英对照。每个主题下的「本主题专业词汇」可直达对应记忆卡。搜索支持中文、英文、缩写和学习中出现的相关说法；正文只标注准确对应的英文，不把相关词强行当作同义词。

词汇记忆卡入口：[`learn.html#cards`](./learn.html#cards)。205 张卡支持英文→中文、中文→英文和随机方向；翻开后选择「非常了解 / 模糊 / 不了解」，按模块或状态筛选、优先复习薄弱词、洗牌重测、撤回上次标记。每张卡包含白话定义、概念辨析、教学例子和来源。进度保存在当前浏览器的 localStorage 中，刷新后继续，不会自动跨设备同步。自评状态不代表客观测评结果。

术语数据位于三个 `glossary-*.json` 文件；新增词卡须使用稳定 ID、有效主题 ID 以及来源链接。`terms.js` 管理精确术语注释，`memory-core.js` 管理独立的复习状态，`memory.js` 管理交互。搜索别名可以包含相关词，但正文注释白名单仅包含准确对应的词。

- 8 个模块、47 个主题、38 张概念对比表、14 个流程、19 篇主要来源。
- 分层体系图、可展开目录、全文搜索、关联主题与来源索引。
- 原文提炼、经核对的学习延伸、补齐体系的新增框架分别标识。
- 适配手机、平板和桌面；主题链接可以直接分享。

## 运行与维护

无需构建步骤。用任意静态服务器运行这个目录，例如：

```sh
python3 -m http.server 8765
```

打开 `http://localhost:8765`。内容存储在 `knowledge.json`，页面逻辑在 `app.js`，视觉样式在 `styles.css`。

GitHub Pages 从 `main` 分支根目录发布，更新后会重新部署。需要回退时，撤销相应提交并推送即可。

## 内容边界

本站为公开来源的知识整理与应用示例。历史厂商案例不代表当前企业内部架构；具体产品能力以原文与版本为准。法律期限、产品承诺和练习中的项目目标不得互相替代。

发布内容包含知识摘要及公开原文链接，不包含原始聊天记录或私人 PDF。
