# 数据治理知识图谱 · Data Atlas

一套以企业数据管理与治理为主线的中文知识工作台，连接隐私工程、业务风控、AI 数据处理与 TPM 项目交付。

学习版入口：[`learn.html`](./learn.html)。前 1–3 层为体系、模块和主题关键词；第 4 层直接显示具体核心概念、易混对比和系统架构，第 5 层展开对应问题，第 6 层提供解释、表格、机制图与教学例子。导图支持拖动、缩放、折叠和分支定位，讲解区适合连续阅读。

学习版覆盖全部 47 个主题、147 个具体知识分支、190 个细分问题，包含 117 张对比表与 27 张可放大的架构或流程图。每个主题按实际知识关系组织，不套用统一的“白话／例子／比较／自测”分栏。内容位于三个 `conceptmap-*.json` 文件，主题 ID 与 `knowledge.json` 对应。旧 `learning-*.json` 保留为上一版内容，当前学习页不再读取。原有速查版仍从 `index.html` 进入。

可以从 [HDFS 与 Data Lake](./learn.html#life-storage/hdfs-lake)、[POSIX 与 HTTP REST](./learn.html#life-storage/posix-http) 开始。搜索会定位到匹配的知识分支。图中的连线注明组件之间的动作，并区分流程、反馈与控制；点击“放大阅读”可缩放、滚动，并逐条阅读连接关系。教学架构均注明适用边界，不代表某家公司的实际部署。

模块、主题和正文专业词汇提供中英对照。每个主题下的「本主题专业词汇」可直达对应记忆卡。搜索支持中文、英文、缩写和学习中出现的相关说法；正文只标注准确对应的英文，不把相关词强行当作同义词。

词汇记忆卡入口：[`learn.html#cards`](./learn.html#cards)。205 张卡支持英文→中文、中文→英文和随机方向；翻开后选择「非常了解 / 模糊 / 不了解」，按模块或状态筛选、优先复习薄弱词、洗牌重测、撤回上次标记。每张卡包含白话定义、概念辨析、教学例子和来源。进度保存在当前浏览器的 localStorage 中，刷新后继续，不会自动跨设备同步。自评状态不代表客观测评结果。

术语数据位于三个 `glossary-*.json` 文件；新增词卡须使用稳定 ID、有效主题 ID 以及来源链接。`terms.js` 管理精确术语注释，`memory-core.js` 管理独立的复习状态，`memory.js` 管理交互。搜索别名可以包含相关词，但正文注释白名单仅包含准确对应的词。

- 8 个模块、47 个主题、19 篇主要来源及按分支标注的官方补充资料。
- 分层体系图、可展开目录、全文搜索、关联主题与来源索引。
- 原文提炼、经核对的学习延伸、补齐体系的新增框架分别标识。
- 适配手机、平板和桌面；主题链接可以直接分享。

## 运行与维护

无需构建步骤。用任意静态服务器运行这个目录，例如：

```sh
python3 -m http.server 8765
```

打开 `http://localhost:8765/learn.html`。学习页由 `learn.js` / `learn.css` 管理导图与阅读，`concepts.css` 管理概念分支布局，`diagrams.js` 渲染组件及关系。新增分支须保留稳定 ID、中英标题、有效来源与完整图边引用。原速查页的数据和逻辑为 `knowledge.json`、`app.js`、`styles.css`。

GitHub Pages 从 `main` 分支根目录发布，更新后会重新部署。需要回退时，撤销相应提交并推送即可。

## 内容边界

本站为公开来源的知识整理与应用示例。历史厂商案例不代表当前企业内部架构；具体产品能力以原文与版本为准。法律期限、产品承诺和练习中的项目目标不得互相替代。

发布内容包含知识摘要及公开原文链接，不包含原始聊天记录或私人 PDF。
