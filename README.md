# 数据治理知识图谱 · Data Atlas

一套以企业数据管理与治理为主线的中文知识工作台，连接隐私工程、业务风控、AI 数据处理与 TPM 项目交付。

学习版入口：[`learn.html`](./learn.html)。前 1–3 层为体系、模块和主题关键词；第 4 层直接显示具体核心概念、易混对比和系统架构，第 5 层展开对应问题，第 6 层提供解释、表格、机制图与教学例子。导图支持拖动、缩放、折叠和分支定位，讲解区适合连续阅读。

学习版覆盖全部 47 个主题、149 个具体知识分支、201 个细分问题，包含 122 张对比表与 28 张可放大的架构或流程图。每个主题按实际知识关系组织，不套用统一的“白话／例子／比较／自测”分栏。内容位于三个 `conceptmap-*.json` 文件，主题 ID 与 `knowledge.json` 对应。旧 `learning-*.json` 保留为上一版内容，当前学习页不再读取。原有速查版仍从 `index.html` 进入。

问题围绕数据治理、隐私工程、业务风控和跨团队交付的专业任务组织：概念边界、架构与选型、控制设计、故障诊断、效果度量及验收。一次学习对话中的误解不直接充当主问题，具体情境保留为解释和练习。题目是本材料的教学组织，不代表某机构统一题库。

可以从 [HDFS 与 Data Lake](./learn.html#life-storage/hdfs-lake)、[POSIX 与 HTTP REST](./learn.html#life-storage/posix-http) 开始。搜索会定位到匹配的知识分支。图中的连线注明组件之间的动作，并区分流程、反馈与控制；点击“放大阅读”可缩放、滚动，并逐条阅读连接关系。教学架构均注明适用边界，不代表某家公司的实际部署。

模块、主题和正文专业词汇提供中英对照。每个主题下的「本主题专业词汇」可直达对应记忆卡。搜索支持中文、英文、缩写和学习中出现的相关说法；正文只标注准确对应的英文，不把相关词强行当作同义词。

英文优先采用通行术语，并注明厂商或案例语境。在线黑库使用 Online Blacklist，支持 Blocklist / Denylist 检索；解释区区分名单概念、样本索引和最终处置。Evidence Brief、Masking Invariant 等保留案例名称并标明范围；reCAPTCHA Assessment 不作为通用 Risk Assessment 的完整定义。

205 个词条已经按独立考察价值复评：89 个核心考点、87 个支撑概念进入复习；29 个重复或字面说明条目保留正文参照，退出词卡与自动英文注释。原词条 ID 与复习记录保留，旧参考词卡链接会转到对应说明。Precision 以「精确率」为主名称，「查准率」保留为检索别名。

词汇记忆卡入口：[`learn.html#cards`](./learn.html#cards)。176 张精选词卡支持英文→中文、中文→英文和随机方向；翻开后选择「非常了解 / 模糊 / 不了解」，按模块或状态筛选、优先复习薄弱词、洗牌重测、撤回上次标记。每张卡包含专业考点、自检要点、概念辨析、教学例子和来源，并通过场景链接直达具体问题。进度保存在当前浏览器的 localStorage 中，刷新后继续，不会自动跨设备同步。自评状态不代表客观测评结果。

术语数据位于三个 `glossary-*.json` 文件；新增词卡须使用稳定 ID、有效主题 ID 以及来源链接。`terms.js` 管理精确术语注释，`memory-core.js` 管理独立的复习状态，`memory.js` 管理交互。搜索别名可以包含相关词，但正文注释白名单仅包含准确对应的词。

- 8 个模块、47 个主题、19 篇主要来源及按分支标注的官方补充资料。
- 分层体系图、可展开目录、全文搜索、关联主题与来源索引。
- 原文提炼、经核对的学习延伸、补齐体系的新增框架分别标识。
- 适配手机、平板和桌面；主题链接可以直接分享。

## 面试练习

[`interview.html`](./interview.html) 提供数据治理、隐私工程、业务风控三类练习，共 24 道技术简答和 12 道教学场景。支持按领域、类型、关键词筛选与随机抽题；题目先展示，点击展开参考思路、关键考点、失分点及追问。每题连接具体知识问题和相关词卡，题目与筛选可通过 URL 分享。场景是依据公开知识与 JD 编写的练习，不代表 TikTok 内部真题或已知出题频率。

数据位于三个 `interview-*.json` 文件；词条的 `learning` 字段记录保留级别、考点与精确链接，`#topic/section/item` 可直接定位讲解。Lookup Join 专门覆盖机制、连接语义、缓存时效、血缘与隐私关联，并提供跨场景入口。

## 运行与维护

无需构建步骤。用任意静态服务器运行这个目录，例如：

```sh
python3 -m http.server 8765
```

打开 `http://localhost:8765/learn.html`。学习页由 `learn.js` / `learn.css` 管理导图与阅读，`concepts.css` 管理概念分支布局，`diagrams.js` 渲染组件及关系。新增分支须保留稳定 ID、中英标题、有效来源与完整图边引用。原速查页的数据和逻辑为 `knowledge.json`、`app.js`、`styles.css`。

GitHub Pages 从 `main` 分支根目录发布，更新后会重新部署。需要回退时，撤销相应提交并推送即可。

## 内容边界

本站为公开来源的知识整理与应用示例。历史厂商案例不代表当前企业内部架构；具体产品能力以原文与版本为准。法律期限、产品承诺和练习中的项目目标不得互相替代。

发布内容包含知识摘要及公开原文链接，不包含原始聊天记录或私人 PDF。
